# Python - Inheritance

This project covers Python inheritance concepts including class hierarchies,
method overriding, `super()`, `isinstance`, `issubclass`, and custom
exception handling.

## Files

| File | Description |
|------|-------------|
| `0-lookup.py` | Returns list of attributes and methods of an object |
| `1-my_list.py` | `MyList` class inheriting from `list` with `print_sorted()` |
| `2-is_same_class.py` | Returns `True` if object is exactly an instance of a class |
| `3-is_kind_of_class.py` | Returns `True` if object is instance of or inherits from a class |
| `4-inherits_from.py` | Returns `True` only if object inherits from a class |
| `5-base_geometry.py` | Empty `BaseGeometry` class |
| `6-base_geometry.py` | `BaseGeometry` with unimplemented `area()` method |
| `7-base_geometry.py` | `BaseGeometry` with `integer_validator()` method |
| `8-rectangle.py` | `Rectangle` inheriting from `BaseGeometry` |
| `9-rectangle.py` | Full `Rectangle` with `area()` and `__str__()` |
| `10-square.py` | `Square` inheriting from `Rectangle` |
| `11-square.py` | `Square` with custom `__str__()` |
| `100-my_int.py` | `MyInt` class with inverted `==` and `!=` operators |
| `101-add_attribute.py` | Adds new attribute to object if possible |
