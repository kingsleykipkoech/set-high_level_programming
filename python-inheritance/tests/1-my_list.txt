===========================
How to use 1-my_list.py
===========================

This module defines a class ``MyList`` that inherits from ``list``.

Usage
=====

``print_sorted()`` prints the list in ascending sorted order without
modifying the original list.

::

    >>> MyList = __import__('1-my_list').MyList
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is not modified:

::

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Works with negative numbers:

::

    >>> my_list2 = MyList()
    >>> my_list2.append(-3)
    >>> my_list2.append(0)
    >>> my_list2.append(-1)
    >>> my_list2.append(5)
    >>> my_list2.print_sorted()
    [-3, -1, 0, 5]

Original not modified after negative number sort:

::

    >>> print(my_list2)
    [-3, 0, -1, 5]

Empty list:

::

    >>> my_list3 = MyList()
    >>> my_list3.print_sorted()
    []

Already sorted list:

::

    >>> my_list4 = MyList([1, 2, 3])
    >>> my_list4.print_sorted()
    [1, 2, 3]

MyList inherits from list:

::

    >>> my_list5 = MyList()
    >>> isinstance(my_list5, list)
    True
