# Python - Input/Output

This project covers Python file handling, JSON serialization/deserialization,
and log parsing. Tasks include reading/writing files, converting objects to/from
JSON, and building a Student class with serialization support.

## Files

| File | Description |
|------|-------------|
| `0-read_file.py` | Reads a UTF-8 text file and prints to stdout |
| `1-write_file.py` | Writes a string to a file, returns number of chars |
| `2-append_write.py` | Appends a string to a file, returns chars added |
| `3-to_json_string.py` | Returns JSON string representation of an object |
| `4-from_json_string.py` | Returns Python object from a JSON string |
| `5-save_to_json_file.py` | Saves an object to a file as JSON |
| `6-load_from_json_file.py` | Creates an object from a JSON file |
| `7-add_item.py` | Script that adds CLI args to a JSON list file |
| `8-class_to_json.py` | Returns `__dict__` of an object for JSON |
| `9-student.py` | `Student` class with `to_json()` method |
| `10-student.py` | `Student` class with filtered `to_json(attrs)` |
| `11-student.py` | `Student` class with `reload_from_json()` method |
| `12-pascal_triangle.py` | Returns Pascal's triangle as a list of lists |
| `100-append_after.py` | Inserts a line after each line matching a string |
| `101-stats.py` | Reads stdin and computes HTTP log metrics |
