# Python - Everything is Object

This project explores Python's object model — how variables, references,
identity, mutability, and memory work under the hood in CPython.

## Tasks

| File | Answer |
|------|--------|
| `0-answer.txt` – `28-answer.txt` | Conceptual questions about Python objects |
| `19-copy_list.py` | Returns a shallow copy of a list |
| `100-magic_string.py` | Returns "BestSchool" n times per call |
| `101-locked_class.py` | Uses `__slots__` to restrict attributes |
| `103-*.txt` – `106-*.txt` | CPython int/string object internals |
