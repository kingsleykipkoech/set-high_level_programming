# Python - Network 0

Bash scripts using cURL for HTTP requests and a Python peak-finding algorithm.

## Files

| File | Description |
|------|-------------|
| `0-body_size.sh` | Display response body size in bytes |
| `1-body.sh` | Display body of 200 response |
| `2-delete.sh` | Send DELETE request |
| `3-methods.sh` | Display allowed HTTP methods |
| `4-header.sh` | Send GET with custom header |
| `5-post_params.sh` | Send POST with parameters |
| `6-peak.py` | Find peak in unsorted list (O(log(n))) |
| `100-status_code.sh` | Display only status code |
| `101-post_json.sh` | Send JSON POST from file |
| `102-catch_me.sh` | Trigger "You got me!" response |
