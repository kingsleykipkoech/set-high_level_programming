# Python - Test-Driven Development

This project covers Test-Driven Development (TDD) in Python using doctests and
unittests. Each function is built alongside its test cases to ensure correctness
before and after implementation.

## Files

| File | Description |
|------|-------------|
| `0-add_integer.py` | Adds 2 integers/floats with type validation |
| `2-matrix_divided.py` | Divides all matrix elements by a divisor |
| `3-say_my_name.py` | Prints "My name is first_name last_name" |
| `4-print_square.py` | Prints a square of `#` characters |
| `5-text_indentation.py` | Prints text with 2 newlines after `.`, `?`, `:` |
| `6-max_integer.py` | Finds the max integer in a list |
| `100-matrix_mul.py` | Multiplies two matrices manually |
| `101-lazy_matrix_mul.py` | Multiplies two matrices using NumPy |

## Tests

| Test File | Description |
|-----------|-------------|
| `tests/0-add_integer.txt` | Doctests for add_integer |
| `tests/2-matrix_divided.txt` | Doctests for matrix_divided |
| `tests/3-say_my_name.txt` | Doctests for say_my_name |
| `tests/4-print_square.txt` | Doctests for print_square |
| `tests/5-text_indentation.txt` | Doctests for text_indentation |
| `tests/6-max_integer_test.py` | Unittests for max_integer |
| `tests/100-matrix_mul.txt` | Doctests for matrix_mul |
| `tests/101-lazy_matrix_mul.txt` | Doctests for lazy_matrix_mul |
