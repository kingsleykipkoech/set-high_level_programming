# Python - Network 1

This project covers making HTTP requests in Python using standard library
`urllib` as well as the third-party `requests` library.

## Files

| File | Description |
|------|-------------|
| `0-hbtn_status.py` | Fetch status with `urllib` |
| `1-hbtn_header.py` | Get `X-Request-Id` with `urllib` |
| `2-post_email.py` | POST email with `urllib` |
| `3-error_code.py` | Handle `HTTPError` with `urllib` |
| `4-hbtn_status.py` | Fetch status with `requests` |
| `5-hbtn_header.py` | Get `X-Request-Id` with `requests` |
| `6-post_email.py` | POST email with `requests` |
| `7-error_code.py` | Error handling with `requests` |
| `8-json_api.py` | Search API with POST and JSON handling |
| `10-my_github.py` | GitHub user info via Basic Auth |
| `100-github_commits.py` | List 10 most recent GitHub commits |
